# Numerical Methods course agents

These are the class agents and teaching material for the Numerical Methods course. They predate the thesis.

- `docs/`: laboratories, student guides and teaching notes (in Spanish).
- The agents' code is the `didactica/` package at the repository root. It was not moved here because `unirl` and the tests import it.
